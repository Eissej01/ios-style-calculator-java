# iOS Style Calculator in Java 

A sleek desktop calculator application built using Java Swing, featuring a clean user interface inspired by the iOS calculator design.

## Features 
* **Standard Arithmetic:** Supports addition, subtraction, multiplication, and division (`+`, `-`, `×`, `÷`).
* **Utility Functions:** Includes All Clear (`AC`), sign toggling (`+/-`), and percentage calculation (`%`).
* **Modern UI:** Custom color schemes and button styling mimicking a modern mobile calculator look and feel on desktop.

## Built With 🛠️
* **Java** 
* **Java Swing** (AWT & Swing libraries for the graphical user interface)
